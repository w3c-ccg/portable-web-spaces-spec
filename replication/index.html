Replication for Portable Web Spaces v0.1

This document defines the replication profile for Portable Web Spaces (PWS), a pull-only transport by which a Space held on one server is copied to, and kept converged with, a Space on another server. A Space's controller registers the source on the replica server and delegates it a read-only capability. The replica server pulls the source's changes feed, applies each record by its origin write stamp, and serves the loop's state. The document defines the registration record and its checks, the pull loop, the per-kind apply rules, the replicated resolution of a controller's log, and the bounds on the one network fetch a source server makes.

This is an experimental specification and is undergoing regular revisions. It is a companion to the Portable Web Spaces specification, which defines the storage API and the data model this document moves between servers.

This document binds servers. A server that implements it lists a version entry under https://w3id.org/pws/replication in its PWS service description, and that listing is the claim that it serves the registration sub-resource, runs the pull loop and applies what it reads as this document requires. A server that does not implement it lists no entry, holds no replica, and may still be the source of another server's pull.
